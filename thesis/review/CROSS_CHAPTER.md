# 跨章问题与修改顺序

逐条批注见 `*.review.md`（150 条）。这一页只讲**必须整篇一起改、单章改会改乱**的十一件事，以及建议的动手顺序。

## X-1 🔴 “到底证明了什么”的口径在四处不一致

全轮最重要的发现，也是唯一一个能同时被二审、审稿人和答辩老师抓住的问题。同一件事在四处的强度递减：

| 位置 | 措辞 | 读者形成的预期 |
|---|---|---|
| 摘要 | “a **proved** consistency/robustness trade-off inequality … a budget–stakes **reading**” | 本文有理论结果 |
| §1.3 第 5 条贡献 | 把 §6.3 的实验发现与 §10.2 的展望打包成**一条贡献** | 展望是贡献之一 |
| §10.2 | “the budget **is achievable**”“**no** rule … at **any** prefix length” | 有一个上下界匹配的定理 |
| §10.3 限制 | “no theorem beyond the stated inequality is claimed here” | 其实什么都没证 |

**改法（自上而下统一到最保守的那一档）**：摘要加限定（A-05）→ §1.3 拆条（1-12）→ §10.2 节首界定 + 两处强断言降级（10-04、10-07、10-08）→ §10.3 不动。
顺带把 `law` 全部改成 `reading` 或 `conjecture`。

## X-2 🔴 “基线 / floor”在全文有五个不同的数

Table 4.1 三个面板的 floor 是 0.948 / 0.890 / 0.990（4-06），§6.1 写 ≈0.99、§6.4 又出现 0.990 与 0.958（6-15）。
它们来自不同图族，但正文没有任何提示，读者只会得出一个结论：数字对不上。

**改法**：表注加一句 floor 是实例相关的（Ranking 在该面板自己图族上的比值）；第 6 章每个 floor 数就地标注实例设置；全文 grep 一遍所有基线数字。

## X-3 🔴 L1 距离与总变差距离被当作同义词

§2.5 写 “L1 (total-variation) distance”，但 TV = L1／2。第 6 章的阈值（τ ≈ 2(1−β)）、§10.2 的仿射律都对这个因子敏感（2-10）。
审稿人一定会核对常数。

**改法**：全文统一用 L1（算法和实验都是 L1），在 §2.5 明写 “it is twice the total-variation distance”，然后回头核对 §6.2、§6.3、§10.2 里每一个带 2 或 ½ 的常数。

## X-4 🔴 符号复用：p、r、b/c

- **p**：§2.2、§3.1 是类型分布；§5.1 的 `p[μ]` 是真实权重向量（5-02）。两处都在讨论预测误差，第 5 章的核心公式因此可能被读错。
- **r**：§3.1 是请求类型数；§2.5 是分布支撑大小（2-11）。二者恰好相等，但从没说破。
- **b / c**：§9.1 同一句里 b-matching 的 b 与容量 c 指同一件事（9-03）。

**改法**：§5.1 的真实权重改用 `w`；§2.5 加半句说明 r 就是类型数；第 9 章统一用一个字母。三处都是一行改动，消除的是真实的误读风险。

## X-8 🟡 “wall” 比喻与 gap-capture 指标都是先用后定义

- **wall**：§1.3 首次使用，§8.4 才有正式说明（1-14、10-15）。
- **gap-capture**：§7.1 与 §8.1 各用一次，两处都没有定义式（7-03、8-04）。它是本文讲“上升空间小”的主力指标。

## X-11 🟡 统计与对照组的两个方法学缺口

- **配对试验却报独立 CI**（3-10）：既然每个比较都复用同一批图、同一条到达序列和同一个 OPT，算法之间的差异应报**配对差**的置信区间；现在报的是各自比值的 CI，会系统性高估差异的不确定性。第 4 章的结论正是靠这些区间支撑的。
- **clairvoyant oracle 未必最优**（8-08、8-09）：§8.2 把“按未来 burst 预留”的策略当作上界，但正文自己写了一个非预测策略**跑赢**了它——这恰恰说明它不是最优。而“非预测策略追平 oracle”正是该节的结论。

两条都是审稿人最可能要求补做的，成本都不高（前者重算一次 CI，后者要么论证最优性、要么把 oracle 降级为 baseline）。

1. **X-1 口径统一**（半天）——风险最高，且会连带改动摘要、§1.3、§10.2 的措辞，先做完再动文字。

4. **X-11 两个方法学缺口**（一天）——配对 CI 重算 + oracle 措辞或论证。
5. **各章 🔴 必改逐条**（两天）——见 `SUMMARY.md` 的必改清单，共 54 条（去掉上面已覆盖的约 20 条）。
6. **X-5 去重、X-6 外部引用、X-9 companion work、X-10 编号对齐**（半天）——机械但显著。
7. **🟡 建议逐条**（两天）——主要是长句与信息密度。
