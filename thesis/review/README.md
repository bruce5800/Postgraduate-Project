对象：`thesis/en/*.md`（唯一源文件，`build_school.sh` 由它生成 `thesis.pdf`）。
本轮覆盖**摘要 + Ch1 + Ch6 + Ch10**，共 **60 条批注**（🔴 必改 20 · 🟡 建议 33 · ⚪ 可选 7）。
**正文一字未改**——所有批注以 `<!--REV ... -->` HTML 注释内联，正式构建会剥掉。

## 六个视角

| | 视角 | 管辖范围 |
|---|---|---|
| **R1** | 二审考官（懂算法但不做 learning-augmented） | 术语首次出现是否就地解释、是否默认读者读过某篇文献、符号引入、图注能否脱离正文看懂 |
| **R2** | 领域审稿人（TALG / 实验算法口味） | 断言强度与证据是否匹配、实验条件是否被句子稀释、归属 credit、负结果表述 |
| **R3** | 英语文字编辑（针对非母语作者） | 长句嵌套、冗词、斜体滥用、指代距离、时态与拼写一致 |
| **R4** | 体例校对 | 术语指称漂移、交叉引用、正文与图表数字一致、章末结构平行 |
| **R5** | 答辩提问者 | 哪句话会主动招来不想回答的问题、scope 声明是否滴水不漏 |
| **R6** | 初次读者 | 叙事流、比喻首次落地、章际过渡、单段信息密度 |

严重度：**必改**＝不改会被当场问住或存在一致性风险；**建议**＝明显影响可读性；**可选**＝风格偏好。

## 用法

```bash
cd thesis/review && ./build_review.sh          # 重建批注版 PDF
```

```bash
cd thesis/review && ./check_clean.sh           # 证明批注不影响提交版
```

`check_clean.sh` 用 `build_school.sh` 原样的预处理 + pandoc 调用，对比"带批注"与"删掉全部批注"
两份的生成 LaTeX：逐字节相同即提交版 PDF 不受影响。当前状态：**PASS**。

改完批注后 `python3 gen_review_md.py` 重新生成清单（`*.review.md` 与 `SUMMARY.md` 是生成物，
批注原件在 `en/*.md` 里）。逐条处理完可以直接删掉对应的 `<!--REV -->` 块，或改成
`level: 已处理` 留档。

## 排版与定位

`review_main.tex` 控制版式：正文左栏 `\revleftw`（10.2cm）、批注右栏 `\revrightw`（6.9cm）、
正文 `\small` / 批注 `\footnotesize`。想更紧或更松，改这几个长度和 `\revrowskip` 即可。

原文里的底色由 `rev2tex.py` 自动定位：把批注的 `quote`（`...` 当通配符）在该段的 LaTeX 里
做容错匹配（忽略 pandoc 的换行、破折号与引号变体、跳过数学），再挑其中最长的一段无标记文本
上色。匹配不到就往相邻段落找。60 条里 57 条已定位，另外 3 条（`1-15`、`6-07`、`10-15`）针对的是
整段结构或跨章现象，用 `mark: -` 显式关掉。想改某条的标注位置，在它的 `<!--REV -->` 块里加一行
`mark: <原文里的一小段>` 覆盖即可，重新 `./build_review.sh` 就生效；构建结束会列出未定位的条目。
